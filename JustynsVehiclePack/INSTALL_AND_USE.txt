JUSTYNS VEHICLE PACK - BUILD 42

INSTALL
Extract this ZIP. Copy its JustynsVehiclePack folder into:
  %USERPROFILE%\Zomboid\mods
The installed layout must be:
  Zomboid\mods\JustynsVehiclePack\42\mod.info
  Zomboid\mods\JustynsVehiclePack\common\media\...

Restart Project Zomboid and enable "Justyns vehicle Pack".
Disable the separate Emre RE9 Motorcycle, Land Rover Discovery and Cessna172
mods for this save/server, since they define the same vehicles and scripts.
For an existing save, enable the pack in that save's mod selection too.
Vehicle, item and sandbox names are retained so existing content can still
resolve. Back up your save before switching its enabled mods.
When upgrading from Emre Adventure Vehicle Pack, replace/rename the old
EmreAdventureVehiclePack folder. Keep only one installed copy: the internal
mod ID remains EmreAdventureVehiclePack_B42 for existing saves and servers.

INCLUDED CHANGES
RE9: 80 mph native speed ceiling with low-speed tuning preserved; smoother
upper-RPM audio; front cases 50 each, rear side cases 100 each, top case 250.
Camel Discovery: black body, no side Camel logos or hood badge, dark rims,
trunk 450.
All three supplied Discovery variants are included.
All Rover variants have a fitted cabin with pickup-derived dashboard/steering
wheel, two front seats and a rear bench, floor and inner panels. Glass uses its
original transparent mask/texture. Seats follow native install/removal behavior.
Cessna: yellow body with black main-wing tips only, baggage compartment 800. The full
flight model, Aviation books/skill, cockpit HUD and original spawn settings
are included. Aviation level 2 is still required for flight.
Single-player/multiplayer rear motorcycle carrier: see 42/REAR_CARRIER.txt.

SHARING AND MULTIPLAYER
Share this one ZIP. Each friend installs and enables the same pack/version.
Local multiplayer server Mods entry: EmreAdventureVehiclePack_B42
This local ZIP has no Steam Workshop ID; do not enter its mod ID as a
WorkshopItems number. The rear motorcycle carrier supports multiplayer;
the server validates loading/unloading and each client follows the car's
received transform. All clients and the server must use pack v1.0.7.
Dedicated-server loading passed with real vehicle APIs. Actual multiplayer
driving and streaming still need an in-game check.

Build 41 is not included. This is a local package, not a Workshop upload.

retaining EmreAdventureVehiclePack_B42 so saves/server settings stay compatible.
